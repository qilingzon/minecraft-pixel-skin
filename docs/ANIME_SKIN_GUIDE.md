# Minecraft 二次元高精皮肤设计与工程化避坑指南

本文档总结了在 AI Agent 辅助制作与程序化生成 Minecraft 64×64 高精二次元皮肤过程中，经过多轮实测迭代沉淀的**像素美学法则、色彩物理特性与工程避坑实践**。

---

## 一、 8×8 头部像素美学法则

Minecraft 头部的正面有效像素仅有 8×8（共 64 个像素点）。在如此微小的空间内表现二次元萌系角色的神态，必须严格遵循空间优先级：

### 1. 幼态“无口”法则（彻底杜绝“山羊胡/胡渣点”）
- **典型误区**：在 Row 7（下巴行）中央点上 1~2 个深色/红色像素作为“嘴巴”。
- **实测后果**：在 Minecraft 3D 渲染与走动动作中，由于没有空间容纳下唇和下巴的留白，该点会直接被肉眼感知为“长了黑痣”或“山羊胡”。
- **黄金实践**：
  - Row 7 必须保持为**纯净肤色**；
  - 角色神态依靠**眼睛弧度**与**两颊腮红**传递；
  - 极小尺寸下，“无口”在日系二次元风格中能产生极其干净幼态的视觉效果。

### 2. 8×8 面容黄金行分布
```text
Row 0: 顶层发际线与额头高光
Row 1: 刘海主色
Row 2: 额头留白与发丝碎发
Row 3: 上眼睑与眼睫毛主轮廓 (深色浓密睫毛)
Row 4: 瞳孔虹膜上部 (深色) + 外眼角
Row 5: 瞳孔虹膜下部 (明亮浅色) + 纯白高光点
Row 6: 卧蚕浅肤色 + 两颊蜜桃腮红晕染 (x=1..2, x=5..6)
Row 7: 纯净瓷白下巴 (全为肤色，严禁点暗色嘴巴)
```

### 3. 眼部高光与透明感
- 采用 2 格高双层瞳色结构：上方深色阴影、下方明亮反射；
- 白高光必须置于虹膜下缘或外侧，形成晶莹的水润反光；
- 睫毛仅允许占据第 3 行，严禁在头部最外侧边缘（x=0 或 x=7）点缀深黑睫毛，否则在 3D 侧视或旋转时会漏到发际线边缘形成“黑斑”。

## 二、 色彩科学与 Minecraft 3D 渲染避坑

### 1. 告别“屎黄色”——低饱和高明度金发调色
- **现象**：在 2D 绘图软件中看着鲜艳的金黄色（如 `#FFD700`, `#FFDA55`），导入 Minecraft 3D 引擎后往往显得暗沉发污（像“屎黄色”），暗部显得脏乱。
- **机理**：Minecraft 3D 视口对多面体会自动施加漫反射光照削弱（如顶面 100%、正侧面 80%、底面 60%）。如果金黄色底色的色相偏土黄，且阴影层对比度过大（明度差 > 40），光照衰减后阴影直接跌入土褐色泥潭。
- **解决方案（4 阶奶油香草金体系）**：
  - **高光 (Highlight)**：`#FFF7C3`（极高明度奶油白金）
  - **基底 (Base)**：`#FCEBA8`（温润香草金）
  - **过渡 (Midtone)**：`#F6DA96`（略带粉桃的柔和浅金）
  - **阴影 (Shade)**：`#EBC682`（暖蜂蜜色，禁止混入灰黑色素）

### 2. 远距离下采样引发的“假黑斑”
- **现象**：角色发饰上有精致的宝石（如王冠上的红宝石 `#9E1638`），在 3D 视口拉远后，头发上出现极其突兀的黑点。
- **机理**：当像素缩小抗锯齿时，孤立的极深色像素与其周围的极亮金发混合，单像素的高对比度在低频信号下被显著放大。
- **解决方案**：在极小部件上使用**同色系中高明度提亮色**（例如皇冠宝石改用洋红粉 `#FF6B8B` 代替暗红宝石）。

## 三、 双层立体（Base + Outer）服装建模法则

Minecraft 皮肤支持 0.25 格外扩的第二层（Outer Layer），合理分配基础层与外层是提升皮肤精致度的关键：

### 1. 裙摆的高低层次（前短后长）
- **正面**：在基础层绘制腿部过膝长筒袜，外层裙摆在正面设计**倒 V 字蕾丝开衩**，行走奔跑时富有层次动感；
- **背面**：背面身体与腿部铺满裙身，形成端庄大气的拖尾全覆式礼服，下边缘点缀荷叶边与蕾丝；
- **侧面过渡**：侧面裙摆随高度倾斜连接，避免前后产生硬切断层。

### 2. 避免 Z-Fighting 与边缘漏色
- 外层区域除需要凸起的立体结构（刘海发丝、袖口花边、腰间蝴蝶结、头顶王冠）外，其余不需要外扩的面**必须填入透明像素 `(0, 0, 0, 0)`**；
- 基础层所有面的 Alpha 必须为 255（不透明），杜绝半透明漏肉。

## 四、 自动化 CI / QA 规范与审查流水线

1. **语法与像素合规性（Deterministic Validation）**：
   - 运行 `python scripts/skin_tools.py validate <skin_path> <model>`；
   - 检查 0 像素越界、0 非法透明、0 保护区覆盖。
2. **多视角无头 3D 渲染（Visual Inspection）**：
   - 运行 `python scripts/render_showcase.py --skin <path> --output <render.png>`；
   - 审查正面、背面、侧面 3/4 俯视角度，确保无视线死角穿模。
